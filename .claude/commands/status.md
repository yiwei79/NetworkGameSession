# Project Status Check

**Recommended Model: Haiku** (lightweight status lookup)

Read and summarize the current project status from these files:

1. **Docs/Workflow/PROJECT_STATUS.md** - Current phase, recent sessions, next steps
2. **CLAUDE.md** - Master context (Current Status section)

Provide a concise summary including:
- Current phase and progress percentage
- What was completed in the last session
- What's next (with specific task IDs if available)
- Any blockers or decisions needed

Format as a brief status report (under 20 lines).
